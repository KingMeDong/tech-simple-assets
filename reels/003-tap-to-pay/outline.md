Final narration is in `script.json`; visuals in `scene.js`; caption in

## Angle

Tap to pay feels like the card "sends" something. In fact the card is dead
until the terminal's magnetic field powers it, it answers without a
transmitter (by changing how much power it draws), and it pays with a code
that only works once. All devices are generic drawings: no brands, no real
card or terminal designs, no contactless trademark symbol.

## Facts and evidence

| Claim | Evidence | Status |
|---|---|---|
| The card has no battery; the terminal powers the chip | EMVCo, *EMV Chip At A Glance*: "For both contact and contactless payments, the acceptance terminal provides power to the chip to enable the chip to function." NXP AN13453: an ISO/IEC 14443 card is "a passive device (without battery)" "powered by magnetic field generated by a PCD". | **primary** |
| A coil in the terminal creates the magnetic field | NXP AN11706: the ISO/IEC 14443 reader antenna coil "generates the magnetic field to provide the power to operate a card (PICC)". | **primary** (chip maker) |
| The field reaches just a few centimetres | EMVCo eBook: "a maximum distance of a few centimetres". | **primary** |
| A loop antenna in the card catches the field | NXP AN13453: the card "requires a loop antenna"; card with coil antenna = transponder. | **primary** (chip maker) |
| The card answers without transmitting, by load modulation | NXP AN11706: the passive side "uses the load modulation principle to send its data"; reader tests check the card's load-modulation response. Wikipedia ISO/IEC 14443 (secondary) agrees. | **primary** (chip maker); simplified to "flickers how much power it draws" |
| A one-time code for every payment | EMVCo eBook and EMVCo Contactless QRG: chip "generates a one-time use security code for every transaction". | **primary** |
| Phones send a token instead of the real card number | EMVCo: EMV Payment Tokenisation for mobile devices replaces "valuable card data in a transaction with a payment token". Apple Platform Security (Device Account Number) via search summary only; support.apple.com returned HTTP 429 to our fetch. | **primary** (EMVCo) |

**Wording guardrails:**
- Do not say a contactless *card* hides its card number: EMV cards still send
  the card number with the one-time code. Only phones/wallets replace it with
  a token. The script says the code "won't work again", not that the card
  number is secret.
- "Copy it, and it won't work again" = the one-time security code; no claim
  that contactless cards are fraud-proof.
- 13.56 MHz is true (NXP notes) but left out of the script; no exact
  distance is given ("a few centimetres", as EMVCo says).

## Lessons from production

- Whisper heard "tap-to-pay" as "TAPPA pay": the voice uses "tap to pay",
  the on-screen title keeps "tap-to-pay" (in a nowrap span so it never
  breaks at the hyphen).
- "Your card doesn't…" was heard as "Your car…"; "Your payment card" is
  clear. "stand-in" was heard as "standing"; "substitute" is clear.
- "centimetres" is transcribed in US spelling; spoken correctly.
