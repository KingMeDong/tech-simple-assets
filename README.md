# tech-simple-assets

Assets and workflow for **tech.simple.explained**: everyday technology,
explained simply, as short animated videos.

- Instagram: [@tech.simple.explained](https://www.instagram.com/tech.simple.explained/)
- YouTube Shorts: [@tech.simple.explained](https://www.youtube.com/@tech.simple.explained)

Media files in this repo are served to Instagram and YouTube through jsDelivr
(pinned to a commit). See [CLAUDE.md](CLAUDE.md) for the full workflow and
[docs/playbook.md](docs/playbook.md) for the rules and evidence behind it.
